## 📈 Data Flow

```
Purchase → Payment → Firestore Update → Access Granted
    │          │            │                  │
    ▼          ▼            ▼                  ▼
  Select    PayHere    Set Fields        Open Screen
   Plan     Payment    planType          Start Timer
            Success    aiTotal=1200      Load JotForm
                      aiUsed=0
                      aiEnabled=true

Usage → Time Tracking → Save → Check Limit
   │           │          │          │
   ▼           ▼          ▼          ▼
 User      Count Down   Update    If Used>=Total
 Uses AI   Every Sec    Firestore  → Disable
           In AppBar    aiUsed++     aiEnabled=false
```
